# BetaCalendars StaticGrid

Deterministic Gregorian calendar topology for D, with compile-time month
layouts, fixed-capacity runtime grids, cell masks, and undated blank grids.

The API is available at [the generated module reference](api/betacalendars.staticgrid.html).

## Project context

This package is part of [BetaCalendars](https://www.betacalendars.com/).
Structural examples are available as a [blank calendar](https://www.betacalendars.com/blank-calendar).
Four example months used during validation are [November](https://www.betacalendars.com/november-calendar.html),
[December](https://www.betacalendars.com/december-calendar.html),
[January](https://www.betacalendars.com/january-calendar.html), and
[February](https://www.betacalendars.com/february-calendar.html).
