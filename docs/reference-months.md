# Reference months

These months cover changing month lengths and a civil-year boundary. The
linked project pages are examples for visual reference; the library calculates
its results from Gregorian rules rather than reading those pages.

| Month | Days | First weekday |
| --- | ---: | --- |
| [November 2026](https://www.betacalendars.com/november-calendar.html) | 30 | Sunday |
| [December 2026](https://www.betacalendars.com/december-calendar.html) | 31 | Tuesday |
| [January 2027](https://www.betacalendars.com/january-calendar.html) | 31 | Friday |
| [February 2027](https://www.betacalendars.com/february-calendar.html) | 28 | Monday |

For every week start, fixed mode has 42 cells. Natural mode has the minimum
number of complete rows. Adjacent dates cross from December 2026 into January
2027 using real civil dates.
